# Diretrizes de implementação

O documento [PROMPT.md](PROMPT.md) preserva integralmente o prompt publicado na conversa. Estas diretrizes complementam a especificação para a construção deste repositório.

1. Toda a interface, mensagens, templates, dados demonstrativos e documentação de operação devem estar em pt-BR.
2. Identificadores de código, URLs e bibliotecas podem usar inglês; datas e números visíveis usam `pt-BR`.
3. A marca é Atelier Desk, com identidade própria, mantendo a experiência espacial e os comportamentos descritos no prompt.
4. Cada etapa funcional deve ser verificada antes de commit e push. Registrar comandos e resultados reais; nunca marcar recursos simulados como concluídos.
5. O repositório é público. Não publicar segredos, dados de usuários, credenciais de produção ou arquivos locais.
6. Não fazer perguntas de esclarecimento: documentar escolhas técnicas e premissas explicitamente.
7. Construir uma aplicação real, incluindo API, banco, armazenamento, sincronização e exportações. Documentar limites concretos quando não houver dependência externa disponível.
